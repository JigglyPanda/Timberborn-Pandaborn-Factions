# Icon pipeline

Procedural line-art icons in the vanilla Timberborn style: goods, buildings, plants and the faction logo; also the
banner decals, the bottom-bar tool group icon and the store art. All art is generated by the code in this folder and is AI-generated; nothing is hand painted, traced
from game art or taken from other mods. Style rules, findings and open issues: [docs/tech/icons.md](../../../docs/tech/icons.md).

## One command

```
E:\PandabornDev\tools\venv\Scripts\python.exe -I src/pipeline/icons/build_icons.py            # everything
E:\PandabornDev\tools\venv\Scripts\python.exe -I src/pipeline/icons/build_icons.py Tea Rice   # some ids
E:\PandabornDev\tools\venv\Scripts\python.exe -I src/pipeline/icons/build_icons.py --no-mod   # leave the mod alone
```

Writes shipped icons and their `.png.meta.json` to `mod/PandabornFactions/Sprites/Pandaborn/<Group>/`, and to
`E:\PandabornDev\build\icons\`: `rendered/<Group>/` (shipped icons; `unshipped/` holds the rest), `preview/` (4x), and per group
`<group>_sheet.png` (vanilla reference, ours at texture size, then 1/2 and ~1/3 size on UI colours),
`<group>_large.png` (3x) and `<group>_blind.png` (ours and vanilla shuffled). Takes a few seconds.

Needs the venv (numpy, Pillow, scipy for measuring; UnityPy for extraction). No Blender (the superseded
`ox_avatar.py` aside). The run also paints the bottom-bar tool group icon (`toolgroup.py`).

```
E:\PandabornDev\tools\venv\Scripts\python.exe -I src/pipeline/icons/toolbar_sheet.py    # the toolbar, after generate
E:\PandabornDev\tools\venv\Scripts\python.exe -I src/pipeline/icons/model_compare.py    # models beside icons
E:\PandabornDev\tools\venv\Scripts\python.exe -I src/pipeline/icons/banners.py          # banner decals (~30 s)
E:\PandabornDev\tools\venv\Scripts\python.exe -I src/pipeline/icons/toolgroup.py        # tool group icon alone
E:\PandabornDev\tools\venv\Scripts\python.exe -I src/pipeline/icons/store.py            # Workshop preview, thumbnail.png (~5 s)
```

## Files

| File | What |
|---|---|
| `ink.py` | The engine: paths (`line`, `spline`, `ellipse`, `arc`, `rrect`, `bez`, `hatch`, `clip`), the `Icon` drawing calls, the `Style` presets (`GOODS`, `PLANT`, `BUILDING`, `LOGO`), the renderer (8x supersampled, wobble, shadow) and the `@icon` registry |
| `goods.py` | One function per good, plus shared motifs (pole, grain, steam, bowl, chili...) |
| `buildings.py` | One function per new building, plus building motifs (roof, timber frame, lantern, wheel, flume...) |
| `plants.py` | Plant icons |
| `logo.py` | Inkpaws logo: three candidates and the pick |
| `build_icons.py` | Renders everything, writes sprites + meta, calls the contact sheets |
| `contact_sheet.py` | Review sheets beside vanilla |
| `toolgroup.py` | The bottom-bar tool group icon (Night Watch) in the bottom bar's painted style: `Sprites/Pandaborn/BottomBar/PandabornNightWatchIcon.png`, `toolgroups_sheet.png` |
| `store.py` | Store art from pictures in the repo, Pillow only: `art/store/workshop_preview_1280x720.png` (= the mod's `thumbnail.png`, the Steam Workshop preview) and `art/store/thumbnail_square_1024.png` |
| `toolbar_sheet.py` | The whole Inkpaws building toolbar (ours and the kept vanilla icons) by tool group, at 56 and 40 px, from the generated mod (`--gen DIR`): `toolbar_sheet.png`, coverage printed |
| `model_compare.py` | Each building's model (the game-zoom preview when there is one) beside its icon: `models_<n>.png` |
| `banners.py` | The ten banner decals (`Materials/Pandaborn/Decals/Banners/PandabornBanner*.png`) and `banners_sheet.png` |
| `ox_avatar.py`, `bl_ox_avatar.py` | **Superseded.** The shipped bot avatar (`Sprites/Pandaborn/Avatars/InkpawsBot.png`) is the characters lane's render of the real Wooden Ox. These draw the older generic plank ox, are part of no build, write to `E:\PandabornDev\build\icons\ox\` and refuse any path inside `mod/` |
| `extract_vanilla_icons.py` | Pulls vanilla icons out of the game for reference (full sprite rect restored) |
| `measure_style.py` | Stroke width, extent, coverage, centroid and shadow fit of a folder of icons |

## Adding an icon

See "Adding an icon" in docs/tech/icons.md. In short: a decorated function in `goods.py`, drawn in a 100-unit box
back to front, then run `build_icons.py <Id>` and check the preview and the sheet at 40 px.
